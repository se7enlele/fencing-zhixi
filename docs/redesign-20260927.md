# FencingAI 赛事助手改版 · 2026-09-27

参考用户提供的盈越赛事小助手五张截图，沿用“首页 / 赛事 / 积分 / 我的”信息结构，保留 FencingAI 品牌、既有数据、关注和分析能力。首版完成后，用户明确要求推送线上；现已部署生产，发布记录见文末。

## 页面与交互

| 页面 | 本轮调整 |
| --- | --- |
| 首页 | 全局搜索、分析与关注快捷入口、可切换年月的日历、日/月列表、关注赛事。AI 分析收进可展开区域，详情中的分析入口仍会自动打开它。 |
| 赛事 | 保留年份、地区、年龄、剑种、性别、状态与关注筛选，增加月份筛选。其他实体查询、关注动态收进折叠区域，减少首次进入时的拥挤。 |
| 积分 | 独立入口与明确的数据未接入状态；提供真实的选手记录及赛事入口。没有伪造周积分、榜单时间或排名。 |
| 我的 | 沿用账号、关注、报告和历史，统一卡片、按钮、间距和暖橙色。 |

## 相比参考图的细节选择

- 用小圆点标记有收录赛事的日期，用描边标记今天，用深色块标记选中日期，减少同时使用大片高饱和颜色。
- 跨天及跨月赛事覆盖完整已知日期，月视图每场只列一次。只有年份、月份或日期不合法的记录不编造具体日程。
- 搜索跳转到集中结果页，并重置旧年份、地区、月份和关注过滤，避免“明明有选手却查不到”。
- 首页赛事卡片直接提供查看与关注，已关注状态明确；管理与取消关注沿用“我的”。
- 日期无结果明确写“暂无收录不代表没有比赛”，数据加载失败另行提示并支持重试。
- 延续现有键盘和语义控件，新增控件提供标签与选择状态；支持安全区及减少动态效果偏好。
