## 确认的问题与调整

1. 运动员“查看成长分析”曾调用通用 `submitAiQuery`，强制切回首页。现改为按运动员 ID 打开独立成长报告。
2. 通用分析、历史分析的结果曾放在首页折叠区，与首页日历混合。现统一进入“专项分析”页；首页只保留入口，不重复渲染分析表单。
3. 运动员“对手对比”原问题只包含一位选手，实际生成成长分析。现仅在有已收录对手时显示具体的“与某选手对比”，并传入两位选手以生成对比结果。
4. “复制成长页”原链接使用 `?athlete=`，打开的是运动员画像。现使用 `?growth=`，直达对应成长报告。
5. 从分享链接进入运动员画像后，详情未进入统一选手缓存，成长报告可能引用较旧的关注摘要。现将详情并入选手数据，再生成报告。
6. 切换页面时地址栏会保留旧的运动员参数，刷新后跳回错误页面。现主页面、赛事/项目、选手/俱乐部详情、三类报告和专项分析均与地址参数同步，刷新可恢复对应页面。
7. 运动员画像里的指标区原名“成长报告”，与独立报告重名。现名为“成绩概览”，区分数据摘要和完整判断。
8. “最近分析”中的旧记录在复看时会把指标数组当作对象渲染并报错。现保留新快照的数组格式，并兼容已保存的旧快照。
