# 单败表轮空签位修复

雄安站 U8男子花剑（RZSS2034101MFIU8）原始32表有16个对阵签位，包含2场实际比赛和14个轮空签位。此前本地构建与Worker动态构建均先排除轮空，再生成轮次列表，页面因而错误显示0轮空。

- 轮次列表保留全部淘汰赛记录；实战统计、交手记录及最近比赛仍排除轮空。
- 页面显示实际对阵数、已完成比赛数与轮空晋级人数。轮空卡片显示“轮空晋级”，摘要优先显示实际比赛。
- 静态文件以每轮共享字段表和相同轮次对象压缩对阵；API完整还原原结构，保留空值、零比分、顺序及全部轮空。
- 回归使用该场真实数据，同时检查本地构建、Worker构建、JSON压缩还原与页面渲染。页面应有16张签位卡，摘要为“2场实际对阵 · 2场已完成 · 14人轮空晋级”。
- 完整包体315.64 MiB，未提高既有320 MiB预算。
