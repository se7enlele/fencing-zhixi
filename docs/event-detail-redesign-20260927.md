# 赛事详情本地改版 · 2026-09-27

状态：已于 2026-09-27 发布至 https://fencingai.uk 和 https://www.fencingai.uk 。

## 已实现

- 赛事详情优先展示项目入口，赛事分析位于项目之后。
- 项目按日期、剑种、性别、年龄组、赛制组合筛选，支持重置和无匹配状态。
- 项目页新增参赛名单；根据已有数据默认打开循环赛、淘汰赛、最终排名或名单。
- 选手搜索支持姓名和俱乐部，提供小组、相关淘汰赛轮次、名单或最终排名入口。
- 按身份标识去重；淘汰赛缺少标识时，仅在本项目姓名与俱乐部组合唯一时关联；同名或身份不明不强行关联。
- AI 入口、指标和分析移至赛后复盘页签，保留原有功能。
- 小组矩阵保留固定姓名列，新增胜负文字和浅色区分；淘汰赛支持上一轮、下一轮。
- 未明确胜者的对阵不再默认显示客方晋级。
- 展示已有数据版本提示，不把快照描述为实时成绩。
