# 官方个人积分接入

## 来源与语义

使用中国击剑协会信息平台公开接口，经项目现有 `fencing-proxy` 请求：

- `GET /fencingapi/rankinfo/total/getWeek?season=2026&itemType=I`：周次目录。
- `GET /fencingapi/rankinfo/total/groupcode?season=2026&itemType=I`：真实组别目录。
- `GET /fencingapi/rankinfo/total/week`：传入明确赛季、周次、性别、剑种、组别、页码、姓名和 `size=20`。

官方查询页：<https://fencing.yy-sport.com.cn/#/integral/pintegralranking>。

2026-09-27 核实的最新周榜为第三十八周（09月14日至09月20日）。U10 男子花剑共 1672 人，前三为李禹辰 5772 分、张泽毅 4338 分、李梓坤 3990 分，与用户参考图一致。源站周目录的 `updateTime` 另返回“08月16日”，与周次不一致，因此不把它作为本榜更新时间；界面分别展示官方周次与本系统获取时间。

组别按官方目录提供，包括 U10/U12/U14/U16、17+、公开组、老将组、青年组、成年组。没有在目录中的 U8 不自行补出全国榜。积分完全沿用官方 `totalRank` 与 `totalPoints`，不重新计算，不将单场名次转换成积分。姓名搜索保留官方原始排名，空结果只表示当前所选榜单无匹配。

## 服务与页面

- `GET /api/points/meta` 和 `GET /api/points`：本地与 Worker 共用同一校验和字段白名单。
- 同组、同周、同页请求短时缓存 15 分钟，并合并同时到达的重复请求。普通榜单可保存于既有 KV 的独立 `points:v1:` 前缀，TTL 七天；姓名搜索结果不写入 KV。
- 缓存过期后的请求重新读取官方接口。用户再进入积分页时也会刷新过期元数据，最新周榜跟随官方目录；手动选择的历史周次保留。
- 查询失败仅回退同一查询的已验证数据，返回 `cacheStatus: stale`；没有同条件缓存则明确报错，不改成零人或替换为其他分组。
- `data/points-seed.mjs` 保存各组首页的公开字段作为首次访问遇到源站故障的后备快照，后续页及姓名搜索由真实接口提供。`npm run sync:points` 可重新生成；失败分组单独记录，不编造。
- 页面支持性别、剑种、组别、周次、姓名和分页；加载中隐藏旧筛选结果，并防止较早请求覆盖新筛选。
- 点击查参赛记录进入现有搜索，而不凭同名直接关联个人档案。

## 隐私与边界

返回字段仅含官方排名、积分、姓名、俱乐部、公开选手 ID 与源榜日期。不返回源接口中的出生日期、会员编号、照片地址或完整会员对象。接口使用固定上游地址与枚举参数，不接受任意代理目标。

官方接口间歇超时属已知限制；没有收到有效的 `records/total` 时，不能当成“没有积分”。本次浏览器连接仍不可用，视觉/真实手机操作验收没有完成。
