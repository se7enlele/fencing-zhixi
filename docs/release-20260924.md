# 数据同步修复与发布记录（2026-09-24）

## 已确认的原因与修复

- 本机 Node 请求未使用网络代理，原 PowerShell 回退不能可靠获取数据；转为支持代理环境的 curl，请求保持超时和有限重试。
- 线上 `fencing-proxy` 转发 POST 时未保留 JSON `Content-Type`，报名接口返回 `HttpMediaTypeNotSupportedException`。修复后同一请求返回 `code=0`。
- 旧定时任务在同步步骤持续约 45 分钟后被取消，构建和部署被跳过。保留任务级超时、失败退出码、阶段状态和诊断附件；报名请求使用有限并发。
- 成绩文件 404 且官方排名接口明确返回空数组时，记录为 `unavailableCount`，不伪造排名或当作已导入。超时和源接口报错仍算失败。
- 合入远端已有的 4 个界面调整，避免发布覆盖用户此前的修正。
