# 赛事总列表排序与搜索头部

## 问题与调整

- 选手详情的参赛时间线与赛事总列表使用不同渲染逻辑。此前时间线已修复，总列表仍沿用 API 原始顺序，默认先显示 2021 年比赛。
- 总列表在筛选后统一按明确的比赛日期倒序，再分页。兼容点号、短横线、斜线、中文日期及日期区间，未知/无效日期排最后；同日保留原相对顺序。不用年份或赛季伪造具体比赛日。
- 顶部保留统一搜索；性别、剑种、常用年龄组改成直接点选，默认全部。其他年龄组可打开组别选择。年份、月份、地区、状态和关注范围放入“更多筛选”，默认折叠。
- “收录概况”和“更多查询与数据范围”暂时隐藏；已有统计、搜索实现保留。关注的选手和动态合并到默认收起的“我的关注”。
- 顶部搜索继续查询赛事、地区、选手、俱乐部，以及已收录的教练/裁判。筛选按钮明确标为“筛选赛事”，不把赛事年龄组筛选假装成运动员的年龄筛选。
- 点击维度筛选不清空已选月份；显示额外筛选摘要并提供重置搜索与筛选。选中按钮采用深绿底、白字，与普通按钮明确区分。
- 仅修改前端与测试，没有重新同步或重建比赛数据。

## 验证

- `tools/discovery-view-test.mjs` 覆盖混合日期、2021 与 2026 排序、缺日期放末尾、折叠状态、选中按钮语义及组合筛选月份保留，并接入全量 smoke。
- 全量 smoke 通过。本地实际页面检查 390px 与 320px 无横向溢出；2025 筛选后日期倒序，继续加载由 30 场增加为 60 场且顺序不变；搜索蔡廷彧返回同名档案。
- 默认首先显示已公布的 2026 年 12 月赛程，按比赛日期倒序包含未来赛程；不是按入库时间或距离今天远近排序。
