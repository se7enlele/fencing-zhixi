# 账号与“我的”页面改版

状态：2026-09-30 已整合到页面跳转修复分支并通过本地验证；发布结果见阶段发布记录。

## 页面

- 登录、注册、找回密码分开；字号、间距、触控区域与暖色主按钮统一。
- 密码显隐、确认密码、验证码重发等待、提交期间防重复、错误与成功提示、游客返回入口。
- “我的”未登录态突出头像占位与登录／注册；登录态展示账号名称、关注赛事与选手数量。
- 关注、报告、历史、账号安全等功能收进展开列表，保留已有数据及入口。
- 使用帮助、服务数据说明、账号隐私说明、儿童信息提示均可展开。不冒充正式法律协议；未编造微信登录或主动消息推送。

## 账号行为

- 不再通过第一次登录自动注册。
- 新账号采用邮箱验证码注册，密码 10–64 位；现有手机号／邮箱与旧密码兼容。
- 注册及重置使用加盐 PBKDF2-SHA256 密码记录。
- 验证码 10 分钟有效，重发等待 60 秒，最多 5 次错误尝试；存储哈希，不在接口响应中返回验证码。
- 线上验证码由新增 AccountVerification Durable Object 按邮箱串行验证，避免 KV 的并发重复消费；本地请求队列串行处理。
- 已登录的旧手机号账号可验证当前密码并绑定邮箱，之后可以用该邮箱重置同一账号密码。
- 重置保留关注资料并更换认证版本；旧会话无法通过版本检查。线上用户记录仍保存在 KV，跨区域版本传播受 KV 一致性约束。
- 退出登录调用服务端删除会话，并清除本机登录凭证。

## 尚需配置与验收

2026-09-30 线上 `wrangler secret list` 仅有管理员密码哈希，未发现邮件服务凭据。账号页面会查询 `/api/auth/config`，未配置时显示“邮箱注册与密码找回暂未开放，已有账号可继续登录”，并禁用验证码和注册/重置提交。

采用 [Resend 官方发送接口](https://resend.com/docs/api-reference/emails/send-email)，需要部署环境配置 `RESEND_API_KEY` 和 `AUTH_EMAIL_FROM`（已验证发件地址）。密钥通过本地环境或 Cloudflare secret 配置，不写入源码或聊天。未配置时接口返回不可用，不模拟发送成功。

生产发布还将应用 wrangler.toml 中的 AccountVerification 绑定与首次 SQLite Durable Object migration，配置方式参考 [Cloudflare 文档](https://developers.cloudflare.com/durable-objects/get-started/)。本次仅 dry-run，没有创建线上资源或发送真实邮件。

既有手机号账号如果已经忘记密码且从未绑定邮箱，不能直接用新邮箱接管，需另行验证所有权。没有凭手机号免验证重置的后门。

2026-09-30 本地 Playwright 移动视口验证登录、注册、重置页面、密码显隐、返回与刷新恢复；账号页未出现横向溢出。真实手机触控与真实邮件收发仍待验收。
