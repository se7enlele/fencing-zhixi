# FencingAI 真实用户反馈升级 Backlog

日期：2026-07-21

## 目标

把近期真实用户反馈收敛为可执行升级项。后续产品主链路统一为：

`提问 -> 识别对象 -> 生成判断 -> 展示证据 -> 跳转核对 -> 关注/保存/提醒`

首页负责 AI 提问和判断，数据库负责检索与核对，我的页面负责长期关注、账号、历史和报告。

## P0：必须优先完成

### 1. AI 问答结果聚焦

用户问题：
- 当前回答中仍会出现“分析口径”“判断路径”“后续”“第一版”“待升级”等内部工作流文案。
- 这些内容对用户没有直接价值，会削弱商业产品的专业感。

升级要求：
- AI 回答只保留结论、关键数字、证据入口和下一步动作。
- 不展示系统如何分析、后续计划、技术边界等内部说明。
- 对比类问题必须区分数量优势、成绩优势和效率优势，不能把“参赛多”直接说成“更强”。

验收问题：
- `北京金石和北京艾鲁特U10男花谁更强`
- `这些击剑数据能产生什么商业价值`
- `山东小众体育U8男花怎么样`

验收标准：
- 首屏能看懂结论。
- 页面没有内部过程型文案。
- 每个强结论至少有一个可点击证据。

### 2. 意图识别和证据绑定

用户问题：
- 用户会输入赛事名、城市统计、选手成长、俱乐部对比、赛前报名、教练/裁判等不同问题。
- 如果识别正确但证据跳错，例如 U8 问题跳到 U12 项目，用户会立即失去信任。

升级要求：
- 年份、城市、年龄段、剑种、性别、俱乐部、选手名必须参与证据筛选。
- 如果没有明确对象，先提示用户补充条件或选择关注对象。
- 赛事名问题不能误路由成地区统计。

验收问题：
- `2026年天津有几场比赛`
- `哪场比赛人数最多`
- `北京击剑联赛第一站`
- `蔡廷彧最近有没有进步`
- `分析马潇和陶嘉月的对战情况`

验收标准：
- 识别对象正确。
- 证据页与问题条件一致。
- 未收录时明确说明“当前未收录”，不跳到无关旧数据。

### 3. AI 加载体验

用户问题：
- 点击按钮后需要等待，但中间没有清晰反馈。
- “生成判断”不如“开始分析”自然。

升级要求：
- 按钮文案统一为“开始分析”。
- 点击后立即滚动到结果区。
- 显示分析中状态、骨架屏和简短阶段提示。

验收标准：
- 用户点击后 300ms 内看到状态变化。
- 加载期间不会像页面无响应。
- 加载完成后自动定位到结果。

### 4. 首页信息聚焦

用户问题：
- 首页过长，AI 输入、推荐问题、数据总览、赛事卡片混在一起。
- 首页和数据库页边界不够清晰。

升级要求：
- 首页首屏只保留 AI 提问区、推荐问题、核心关注对象、下一场重点赛事。
- 详细列表和筛选统一进入数据库页。
- 首页统计只展示与用户当前角色或关注对象相关的信息。

验收标准：
- 首页首屏完成主要任务，不需要用户先理解系统结构。
- 数据库页不重复承担首页功能。

## P1：第一批真实用户要用得起来

### 5. 家长成长报告

用户问题：
- 家长不是看数据本身，而是看孩子是否进步、是否稳定、是否值得继续投入。
- 负面或生硬判断会影响接受度。

升级要求：
- 报告结构固定为：近期表现、年度变化、小组稳定性、淘汰赛表现、最好名次、最近名次、下一步观察。
- 文案使用“成长基础期”“稳定积累期”“突破观察期”等建设性表达。
- 不能直接输出刺激性判断。

验收标准：
- 家长一屏能看懂孩子阶段。
- 所有判断都有对应参赛记录。

### 6. 赛前情报包

用户问题：
- 报名中或未开赛时没有成绩，但用户已经有强烈分析需求。
- “潜在对手”和“强手”必须基于“我的孩子”或“我的学员”来判断。

升级要求：
- 支持报名名单数据。
- 未选定孩子/学员时，只展示报名热度、重点俱乐部、历史强手。
- 选定孩子/学员后，再展示熟悉对手、潜在强手、历史交手、备赛重点。

验收标准：
- 报名中、未开赛、比赛中、已结束四种状态各有不同展示。
- 不把报名数据伪装成赛果数据。

### 7. 教练工作台

用户问题：
- 教练进入俱乐部页时，不应看到“我的孩子”。
- 教练关心学员分层、训练重点、留住家长、招生和俱乐部口碑。

升级要求：
- 教练视角默认展示学员分层、重点跟进学员、强项项目、弱项项目、近期赛事。
- 支持按剑种、年龄段、性别拆分。
- 增加可复制的家长沟通摘要。

验收标准：
- 教练流中不出现家长视角模块。
- 教练能快速知道“关注谁、练什么、怎么沟通”。

### 8. 俱乐部招生资产

用户问题：
- 俱乐部需要把成绩变成可以对外表达的招生资产。

升级要求：
- 生成俱乐部名片：代表选手、优势项目、前八、奖牌、最好名次、活跃赛事。
- 文案克制，所有数字可追溯。
- 支持复制摘要或保存卡片。

验收标准：
- 小型剑馆也能生成可信表达。
- 不夸大、不虚构排名。

## P2：支撑持续商业化

### 9. 数据库作为证据层

升级要求：
- 数据库页定位为核对和深度检索。
- 支持赛事、选手、俱乐部、教练、裁判搜索。
- 年份、地区、项目、状态、关注范围统一排序和筛选。
- 从 AI 结果跳转时保留原始问题和筛选条件。

验收标准：
- AI 结果跳到数据库后，不需要用户重新筛选。
- 数据库页不展示内部技术说明。

### 10. 关注、保存、提醒

升级要求：
- 关注对象覆盖选手、赛事、俱乐部和报告。
- 已关注/未关注使用小 tag 或 icon，不占大面积。
- 首页优先展示关注对象的变化和提醒。

验收标准：
- 关注状态清晰但不突兀。
- 用户能从首页回到最近关注对象。

### 11. 账号体系

升级要求：
- 明确已登录和未登录两种状态。
- 未登录：可浏览公开数据，本地保存关注。
- 已登录：同步关注、历史、报告和提醒。
- 第一阶段可用手机号/邮箱加密码；第二阶段接微信登录。

验收标准：
- 已登录时不显示手机号和密码登录表单。
- 未登录时不显示账号级“已选择孩子”等语义。

### 12. 数据覆盖状态

升级要求：
- 区分赛事列表、项目列表、报名名单、成绩数据、教练/裁判目录五层覆盖。
- “没有结果”必须区分未收录、未导入、未开赛、暂无名单、暂无成绩。
- 进行中赛事展示当前可用数据，不当作错误。

验收标准：
- 用户知道当前数据缺在哪一层。
- 不把“未收录”表达成“没有这场比赛”。

## 固定回归问题

每次发布前至少跑下面问题：

1. `2026年天津有几场比赛`
2. `天津近期报名情况`
3. `哪场比赛人数最多`
4. `北京击剑联赛第一站`
5. `北京金石和北京艾鲁特U10男花谁更强`
6. `山东小众体育U8男花怎么样`
7. `山东小众体育最近哪些学员值得关注`
8. `蔡廷彧最近有没有进步`
9. `帮我生成蔡廷彧成长报告`
10. `分析马潇和陶嘉月的对战情况`
11. `某场比赛U8男花淘汰赛表现怎么样`
12. `孩子击剑值不值得继续`

## 当前下一步

1. 首页继续聚焦：减少首屏下方内容堆叠，保留 AI 提问、关注对象和下一场重点赛事。
2. 账号页继续拆状态：未登录只展示登录入口和公开数据说明；已登录只展示账号信息、关注、历史和报告。
3. 教练视角继续深化：俱乐部页从结果展示升级为学员分层、重点跟进、招生素材和赛前提醒。
4. 真实用户审计保持常态化：每次发布继续跑 `npm.cmd run audit:online-ai`，新反馈进入执行板。
